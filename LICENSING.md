# Licensing RunenNet

The current RunenNet source is available under the **GNU General Public License version 3 only (`GPL-3.0-only`)**. The complete public-license text is in [LICENSE](LICENSE).

## Commercial licensing

A separate commercial license may be available from copyright holder(s) that have sufficient rights to grant it. The commercial path is intended for organizations that require rights different from the GPL-3.0-only terms, including proprietary distribution or integration where GPL compliance is not suitable.

A commercial license is a separate agreement. This repository does not define pricing, warranties, indemnities, service levels, support commitments, or other customer-specific commercial terms.

## Earlier revisions

This file establishes the explicit current repository license prospectively from the accepted licensing migration. It does not purport to characterize or retroactively change rights in earlier revisions that did not publish an explicit repository license.

The migration issue and pull request retain the exact transition evidence for repository audit and due diligence.

## Contributions

Commercial dual licensing requires sufficient rights over accepted copyright-bearing repository content. Until Dornglut adopts reviewed inbound contribution terms that preserve the commercial relicensing path, external pull requests that add tracked repository content are not accepted for RunenNet, including code, documentation, tests, examples, build scripts, or assets.

Issue reports, design discussion, reviews, reproducible cases supplied through discussion, and other participation that does not add third-party repository content may still be accepted under the repository's contribution policy.

See Dornglut Engineering ADR 0007 and the organization licensing standard for the governing repository policy.
